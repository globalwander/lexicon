# Lexicon: SAT Vocabulary

A free, installable web app for learning SAT vocabulary.

1. **Check**: a multiple-choice sweep through all 1,500 words, 25 at a time. Misses go to a study pile.
2. **Study**: spaced-repetition flashcards (SM-2) for only the words you missed. New cards start as multiple choice (recognition) and move to flip-and-grade (recall).
3. **Master**: a word counts as mastered once you recall it after a 21-day gap.

Plain HTML, CSS and JavaScript. No build step, no server, no accounts. Progress is stored in the browser on each device; export/import a backup from the More tab.

## Deploy
Push this folder to GitHub, then import the repo in Vercel (Framework preset: "Other", no build command). Every push redeploys.

## Word data
`words.json` was generated by a build script (available on request) from openly licensed sources. See `THIRD_PARTY_NOTICES.txt` (also shown in the app under More > Credits). Keep that file with the app.
